# POWERBI-PROJECT
Data Professional Survey Breakdown:
Project Overview:

This project analyzes survey data collected from data professionals around the world. Using Power BI, I cleaned and transformed the dataset in Power Query and built an interactive dashboard to visualize key insights such as salary trends, job satisfaction, preferred programming languages, and demographic information.

The goal of this project is to understand the profile and preferences of data professionals — including how their roles, skills, and countries relate to salary and happiness levels.

Data Source:

The dataset used in this analysis is provided in the Excel file:
Power BI - Final Project.xlsx

It contains survey responses from 630 participants with details such as:

Job title

Country

Salary

Age

Happiness with job and salary

Preferred programming language

Gender

Difficulty entering the data profession

🧹 Data Cleaning (Power Query)

Data cleaning and transformation steps were performed in Power Query, including:

Removing null and duplicate values

Correcting inconsistent text fields (e.g., job titles, countries)

Formatting numerical columns (salary, age)

Creating calculated columns for average salary and happiness scores

Standardizing categorical responses for analysis
